# 彩鍵のデータ形式

ゲームは起動時にこのフォルダのテキストファイルを読み込んで、曲を鳴らし、譜面を並べます。ここを書き換えれば、プログラムに触れずに曲と譜面を変えられます。

| ファイル | 中身 |
|---|---|
| `songs.json` | 選曲画面に並べる曲の順番（曲idの一覧） |
| `songs/<曲id>.json` | 1曲分の曲データ（テンポ、コード、メロディ、ドラム、ベース、音色、色） |
| `charts/<曲id>.json` | 1曲分の譜面（どの拍に、どの敵が、どの段に出るか） |

どれもJSON形式です。コメントは書けません。

## ゲームの中で試す

選曲画面の「街区をタップしたとき」で選べます。

- **曲データ**：曲をタップすると、その曲のデータが文字で出ます。ほかのAIに渡すときは「コピー」を押します。返ってきたデータを貼りつけて「貼りつけたデータで試す」を押すと、その場で鳴らせます。変えたい項目だけを書いた `{"bpm": 140}` のような短いデータでも構いません。書いていない項目はファイルのままです。新しい `id` を書くと、新しい曲として一覧の最後に足されます。
- **譜面エディタ**：「書き出し」で譜面を文字にし、「読み込み」で貼りつけます。

試したデータは、その端末のブラウザにだけ残ります。気に入ったデータは、ファイルに書き戻して公開します。

## 曲の骨組み（全曲共通、変えられません）

1小節は16分音符16個です。曲は全部で44小節あり、次の区間が並びます（小節番号は0から数えます）。

| 小節 | 区間 | 役割 |
|---|---|---|
| 0〜3 | イントロ | 灰色の街。曲の雰囲気だけ |
| 4〜11 | 溜め | 敵を斬るほど、こもった音が開いていく |
| 12〜19 | サビ | 溜めた色を放つと全楽器が鳴る。メロディどおりに斬る |
| 20〜23 | 間奏 | 一息つく |
| 24〜31 | 溜め | 2回目の溜め |
| 32〜39 | ラスサビ | いちばんの盛り上がり |
| 40〜43 | 締め | 最後の一撃で曲が着地する |

コードとメロディは4小節のループです。曲が流れるあいだ、ずっと繰り返されます。

## 曲データ（songs/<曲id>.json）

音の高さはMIDIの番号で書きます（60 = C4（中央のド）、61 = C#4、72 = C5）。

| 項目 | 意味 | 書き方 |
|---|---|---|
| `id` | 曲のid。ファイル名と同じ | 英小文字 |
| `name` / `sub` / `genre` | 曲名、副題、ジャンル | 文字 |
| `bpm` | テンポ | 60〜220 |
| `diff` | 難しさ | 1〜3 |
| `swing` | 16分の裏を後ろにずらす量 | 0（なし）〜0.3くらい |
| `swing8` | 8分の裏を後ろにずらす量（ジャズのハネ） | 0〜0.7。書かなければなし |
| `ch` | コード4小節分 | `[ベースの音, [和音の音, …]]` を4つ |
| `home` | 締めで着地する和音。書かなければ1小節目の和音 | `[ベースの音, [和音の音, …]]` |
| `mel` | メロディ4小節分 | 小節ごとに `[位置, 音, 長さ]` の並び。位置は0〜15（16分）、長さは16分の個数。3連は 2.67 や 5.33 のような小数で書く。4つ目に `"z"` を付けると、トリル（2音を細かく行き来する）の音になる |
| `end` | ラスサビ最後の小節で、4小節目のメロディの代わりに弾くフレーズ | `[位置, 音, 長さ]` の並び |
| `drums` | ドラムの型 | `k`（キック）`s`（スネア）`h`（ハイハット）`g`（ゴースト）それぞれ16文字。`x` が鳴る、`.` が休み |
| `bass` | ベースの型（毎小節同じ） | `[位置, その小節のベース音からの差, 長さ]` の並び。12で1オクターブ上 |
| `walk` | `true` でウォーキングベース（`bass` は使わない） | true / false |
| `kit` | ドラムの音色 | clean, house, break, funk, ind, pop, edm, rock, trap, jazz, taiko |
| `lead` | メロディの音色 | piano, epiano, pluck, saw, square, supersaw, sax, gtr, lofi, shaku（尺八） |
| `pad` | 和音の伸ばし音 | saw, warm, vocoder, gate（刻む）, none |
| `arp` | アルペジオを鳴らすか | true / false |
| `keys` | サビの伴奏 | null, stab, comp, clav, jcomp, power, koto |
| `bassWave` | ベースの音色 | saw, organ, roll, reese, slap, dist, octave, wobble, pick, 808, upright |
| `intro` | イントロの入り方 | arp, piano, swell, rain, drums, machine, chip, pump, riff, vinyl, walk, koto |
| `outro` | 締めの音の消え方 | ring, pianoSolo, swellEnd, fade, hits, powerdown |
| `ending` | 締め方 | tag（最後の一行をくり返して着地）, intro（イントロに戻る）, fade（フェードアウト）, cut（一撃で切る）, stutter, build, rockout, tapestop, turnaround, taiko |
| `keyup` | ラスサビの途中で全音上に転調するか | true / false |
| `hits` / `stab` | 止め打ちで締めるときの打つ位置（16分）と和音の音色 | 数の並び / 音色名 |
| `chartMel` | サビの譜面をメロディのリズムで作るか | true / false |
| `lv` | 区間ごとの音量補正（dB） | 7つの数（イントロ、溜め、サビ、間奏、溜め、ラスサビ、締め） |
| `vol` | 曲全体の音量 | 1が標準 |
| `pal` | 街の色 | top, mid, bot（空）、winA, winB（窓）、signA, signB（看板）、rail, line。どれも `#rrggbb` |

## 譜面（charts/<曲id>.json）

```
{
 "song": "neon",
 "notes": [
  [1,0,"body",0],
  [1,2,"body",0]
 ],
 "holds": [[11,0],[31,0]]
}
```

`notes` の1行が、敵1体です：`[小節, 拍, 種類, 段]`

- **小節**：0〜43
- **拍**：小節の中の位置を、4分音符を1として書きます（0、1、2、3が表拍、0.5が8分の裏、0.25が16分）。3連は1/12刻みの小数（0.3333 など）で書きます。
- **種類**と斬り方：
  - `body`：段の上にいる敵。タップで斬る。その段へ移動しても斬れる
  - `high`：上を飛ぶ敵。上にフリックして跳んで斬る
  - `low`：地面を這う敵。下にフリックして滑りこんで斬る
  - `mid`：段と段の間にいる敵。上下どちら向きの移動でも斬れる
- **段**：0 が上の段、1 が下の段

`holds` は、溜めた色を放つ長押しです：`[小節, 段]`。溜めの最後の小節（11 と 31）のあいだ押し続け、サビの頭で離します。

続けて斬る数で、剣の連撃が変わります。少し間を空けると連撃が区切られます。近すぎる敵や、移動が間に合わない段替えは、エディタが赤で知らせます。
